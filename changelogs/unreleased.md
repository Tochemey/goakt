# Unreleased

## ✨ Features

- **Grain, cluster membership, and scheduler metrics** ([#1324](https://github.com/Tochemey/goakt/issues/1324)). `actorsystem.grains.count` (gauge) reports the grains activated on the local node. `cluster.members.joined.count` and `cluster.members.left.count` (counters, cluster mode only) total the membership churn the local node has observed. `scheduler.scheduled.count` and `scheduler.cancelled.count` (counters) total accepted schedules and honored cancellations. All five are observed at scrape time and no message path is touched.

- **Actor runtime metrics and cardinality control** ([#1323](https://github.com/Tochemey/goakt/issues/1323)). `actor.mailbox.size` (gauge, per actor) reports the pending backlog, the signal that an actor is falling behind its producers; `actor.unhandled.count` totals messages rejected through `ReceiveContext.Unhandled`; `actor.spawned.count`, `actor.stopped.count`, and `actor.passivated.count` count lifecycle edges per actor kind; and `actor.deadletters.count` now carries a `message.type` attribute naming what was dropped. Capture is a plain atomic increment at each site and values are observed at scrape time; only the mailbox gauge lives on the message path, costing one predicted branch per message with metrics off and two atomic adds with metrics on. `WithMetrics(WithLowCardinalityMetrics())` reports the per-actor instruments once per actor kind instead of once per actor, so series count follows declared kinds rather than the actor population; the default per-actor reporting is unchanged.

## 🔧 Fixes

- **Runtime metric instruments report the correct type and the deadletter scrape no longer floods a single mailbox** ([#1322](https://github.com/Tochemey/goakt/issues/1322)). The instruments that report an absolute current value that can fall (`actorsystem.actors.count`, `actorsystem.peers.count`, `actorsystem.uptime`, `actor.children.count`, `actor.stash.size`, `actor.uptime`, `actor.last.received.duration`) were registered as monotonic observable counters, so exporters that derive rates or deltas mishandled every decrease; they are now observable gauges. The per-actor metrics callback asked the deadletter actor for its count once per running actor per scrape, flooding a single mailbox at large populations; it now asks once per scrape for a snapshot of all per-address counts. `crdt.replicator.crossdc.replication.lag` is now reported in milliseconds instead of nanoseconds to match the other duration instruments.
