# v4.6.1 - 2026-10-05

## Fixes

- **Name lookups no longer panic on an actor that is leaving the system** ([#1448](https://github.com/Tochemey/goakt/issues/1448)). `ActorOf`, `ActorExists`, `Kill`, `ReSpawn` and `PID.Child` now answer as they do for an actor that is not on this node.
  - A lookup found the actor's node under the tree lock and read its PID afterwards, and the tree clears that PID when the actor stops.
  - A lookup that found the node just before the actor left read a nil PID and panicked with a nil pointer dereference on the caller's goroutine, which ended the process.
  - It showed up when actors were stopped and looked up by name at the same time, for example while an application stopped.
  - The remoting handlers that look an actor up by address now answer `CODE_NOT_FOUND` for it instead of failing the call.
  - Reliable delivery reports the endpoint's controller as unavailable.
  - Reported by @pablogore in [#1447](https://github.com/Tochemey/goakt/pull/1447). See `playground/issue-1448`.
